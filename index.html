Regiontrace is a regional input-output model for economic impact analysis. You add an event, such as a new plant, a construction project or a closure. Regiontrace estimates the change in output, jobs, labor income, value added and taxes. Regiontrace shows each change as direct, indirect and induced effects.

You build a region from small census areas, such as a city, a county, a school district or a legislative district. A region can also be one area minus another. Regiontrace can model several regions together, with the trade and the commuting between them.

Regiontrace takes every input from published government statistics. With each result, Regiontrace lists the sources and the data release. With this list, anyone can run the study again and get the same result.
